## Modifiers In Classes

| Modifier | Description                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------- |
| public   | The Class is accessible by any other class                                                                                |
| default  | The Class is only accessible by the other classes in the current package. Default is used if you don't specify a modifier |


---
## Modifiers In Attributes - Methods - Constructors

| Modifier  | Description                                                                                      |
| --------- | ------------------------------------------------------------------------------------------------ |
| public    | The Code Is Accessible For All Classes                                                           |
| private   | The Code Is Only Accessible Within The Declared Classes                                          |
| default   | The Code Is Only Accessible in the same package. Default is used if you don't specify a modifier |
| protected | The Code is only accessible in the same package and subclass                                     |
