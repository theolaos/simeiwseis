How To Create An Object :

```java
<Modifier> class <ClassName>
{
	// Example Content
	<DataType> <VariableName> = <Content>;
	
	public static void main (String[] args)
	{
		<ClassName> <ObjectName> = new <ClassName>();
		
		// Example Action
		System.out.println(<ObjectName>.<VariableName>);
	}
}
```


How To Create An Object (Example) :

```java
public class Main
{
	String ExampleString = "ExampleContent";

	public static void main (String[] args)
	{
		Main exampleObj = new Main();
		System.out.println(exampleObj.ExampleString);
	}
}
```


---
Multiple Objects (Example)

```java
public class Main
{
	String ExampleString = "ExampleContent";
	
	public static void Main (String[] args)
	{
		Main exampleObj1 = new Main();
		Main exampleObj2 = new Main();
		System.out.println(exampleObj1.ExampleString);
		System.out.println(exampleObj2.ExampleString);
	}
}
```
