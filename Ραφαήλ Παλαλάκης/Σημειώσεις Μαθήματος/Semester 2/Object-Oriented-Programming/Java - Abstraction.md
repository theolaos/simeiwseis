With **abstraction** we an simplify an object by removing certain **properties**

That way, a developer can hide certain **properties** that are not needed for that specific use case.

**Abstraction** can let us put placeholders for any methods without needing to develop them right away.

Every object must only have one **mechanism**.

With that **mechanism** we can hide any **details** and only show what is relevant for other objects.
