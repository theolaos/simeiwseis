___

How to declare an Array :

```java
<DataType> <ArrayName> [SizeOfArray];
```

OR

```java
<ArrayName> = new <DataType> [SizeOfArray];
```

---
## Multidimensional Arrays

Declaration :

```java
<DataType> <ArrayName> [SizeOfArray_X] [SizeOfArray_Y] ... [SizeOfArray_N];
```

OR

```java
<DataType> [] [] ... [] = new <DataType> [SizeOfArray_X] [SizeOfArray_Y] ... [SizeOfArray_N];
```

---
## Create New Item Inside An Array

Create a new item inside the array this way

```java
<DataType> <ArrayName> [SizeOfArray];

<ArrayName> [IndexOfArray] = new <DataType> = <Value>;
```
