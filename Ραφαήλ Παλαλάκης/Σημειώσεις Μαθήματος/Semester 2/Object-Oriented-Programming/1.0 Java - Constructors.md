## Constructor - Introduction

A Constructor is a special Java Class used to initiate objects

It's called only when an object of class is created

It can also be used to set initial values at the variables

```java
public class Main
{
	int ExampleInteger;
	String ExampleString;
	
	public Main()
	{
		ExampleInteger = 7;
		ExampleString = "Example Content";
	}
	
	public static void main (String[] args)
	{
		Main exampleObj = new Main();
		System.out.println(exampleObj.ExampleInteger);
		System.out.println(exampleObj.ExampleString);
	}
}
```

## Constructor Parameters

Constructors can take parameters to set as values at the initialization of a variable

```java
public class Main {
  int x;

  public Main(int y) {
    x = y;
  }

  public static void main(String[] args) {
    Main myObj = new Main(5);
    System.out.println(myObj.x);
  }
}

// Outputs 5
```
