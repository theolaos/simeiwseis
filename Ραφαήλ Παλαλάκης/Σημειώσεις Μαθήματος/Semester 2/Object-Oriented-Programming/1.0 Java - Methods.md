Create a method inside a class :

```java
<Modifier> class <ClassName>
{
	<MethodAvailability> <StaticStatus> <MethodType> <MethodName>(Parameters)
	{
		// Method Contents
	}
}
```


Example

```java
public class Main
{
	public static void Example()
	{
		System.out.println("Example Content");
	}
}
```
