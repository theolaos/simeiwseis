___
### What Is An Operand?

An operant is the data that an instruction acts upon. All operands fall into one of four categories

___
### The 4 Categories Of Operands

These categories are :
- File Register Operand ($f$)
- Destination Operand ($d$)
- Bit Operand ($b$)
- Literal Operand ($k$)

___
### File Register Operand ~($f$)

The name or an address of a memory location, for example :
- **Hardware Registers** : PORTA, STATUS, INTCON
- **Variables**

___
### Destination Operand ~ ($d$)

A single bit that the CPU reads and puts the result to it's respective place. The possible values are two :
- $0$ : Puts the result in the **Working register**
- $1$ : Puts the result in the **File Register**

___
### Bit Operand ~ ($b$)

A value from **0 to 7** that selects the specific bit you want to work with inside a register.

___
### Literal Operand ~ ($k$)

A constant value that exists directly inside the instruction and is the actual data
