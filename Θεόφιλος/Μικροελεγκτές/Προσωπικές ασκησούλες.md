## Άσκηση:
Άναψε από το `PortB` το `Pin 0` σε `1` (`HIGH`).
## Λύση:
```assemly
; first exersize program

ORG 0x800

CLRF PORTB ; Clearing the port to 0

MOVLW 0x00
MOVWF TRISB ; Setting the direction of transfering information

MOVLW 0x01 ; 8 bits in total, and the port has 8 bits. 
MOVWF PORTB

loop GOTO loop ; "stopping" the microcontroller in a loop

END
```
### Σημειώσεις λύσης:
Η σωστή χρήση σε αυτήν την περίπτωση θα ήταν η χρήση του`LatB` που είναι `SFR`. Καθώς άμα κάνεις `write`  στο `PORTB` έχεις το γνωστό πρόβλημα `RMW`.

Το πρόβλημα `RMW` είναι το `read` όπου μπορεί να διαβάσει λάθος πληροφορίες από τα _φυσικά_ `pin`ακια, `modify `να τροποποιήσεις αυτό που θες και τέλος να κάνεις `write` λάθος πληροφορίες από αυτό που ήθελες στην πραγματικότητα.

## Άσκηση:
Διάβασε από το `RB0`, και όταν γίνεται `HIGH` τότε βάλε ως έξοδο το `HIGH` στο `RD0` αλλιώς η έξοδος να είναι `LOW`.

## Λύση:
```assembly
; Second Exersize
ORG 0x800

CLRF PORTB
CLRF LATD

MOVLW 0x01 ; making RBX input only
MOVWF TRISB

MOVLW 0x00 ; making RDX output only
MOVWF TRISD

loop1:
    BTFSS PORTB, 0 ; checking if the first bit is 1, and skips if True

    GOTO loop1

    BSF LATD, 0 ; setting the first bit to 1.

loop2:
    BTFSC PORTB, 0 ; checking if the first bit is 0, and skips if True

    GOTO loop2

    BCF LATD, 0 ; clearing the first bit

    GOTO loop1

END
```
### Σημειώσεις λύσης:
- `BTFSS f, b (, a=0)`: Bit Test File, _Skip_ if **SET**
- `BTFSC f, b (, a=0)`: Bit Test FIle, _Skip_ if **CLEAR**
- `BCF f, b (, a=0)`: Bit Clear File. **Clears** the bit on the specific bit=`b` from the _register_
- `BSF f, b (, a=0)`: Bit Set File. **Set** the bit on the specific bit=`b` from the _register_
